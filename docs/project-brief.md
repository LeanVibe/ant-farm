# Project Brief: Ant Farm

## Problem
- **Who is the user?** Development teams using AI coding assistants
- **What pain is urgent + expensive?** Need autonomous development workflow that operates 16-24 hours without intervention

## Promise (Painkiller)
- In 1 sentence: Multi-agent development system with Autonomous Development Workflow (ADW) for 16-24 hour autonomous operation
- What is the narrow wedge? ADW system + self-improvement + intelligent coordination + safety controls

## ICP
- **Role:** Engineering teams, development managers
- **Context:** Want AI agents to work autonomously on development tasks
- **Budget:** Enterprise tool pricing ($299-999/month)
- **Trigger:** Need autonomous development capability with safety controls

## MVP Scope (14 days)
- **Critical path:**
  - ADW session management
  - Multi-agent coordination
  - Safety intervention system
  - Cognitive load management
- **Out of scope:**
  - Advanced ML features
  - Multi-tenant support

## Pricing Hypothesis
- **Price:** $299/month for teams, $999/month for enterprise
- **Packaging:** Team: 16-hour sessions, Enterprise: 24-hour + advanced features

## Risks / Assumptions
- Top 3 assumptions to validate first:
  1. Teams need 16-24 hour autonomous operation
  2. Safety controls are sufficient for trust
  3. Multi-CLI support (opencode, Claude, Gemini) is valuable

## Status
- **Intake Date:** 2026-01-20
- **Stack:** Python, FastAPI, PostgreSQL, Redis
- **Repository:** Active git repository
- **Features:** ADW system, multi-agent coordination, emergency intervention, cognitive load management, multi-CLI support
